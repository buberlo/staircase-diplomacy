# Staircase Diplomacy

> Two players share one keyboard and must negotiate every step of an infinite climb.

A local co-op platformer where Player One controls the lower half and Player Two controls the upper half of the same staircase. Steps rotate, tilt, or vanish based on how badly the players’ inputs disagree. The goal is to climb as far as possible while keeping the shared staircase from collapsing into bureaucratic red tape.

## Features
- Two-player local controls on one keyboard with split-axis staircase movement
- Dynamic steps that rotate when players move out of sync for too long
- Climb milestones that unlock new staircase moods and obstacle styles
- Endless score mode with a shared rescue ladder if one player falls

## Stack
- HTML5 Canvas
- TypeScript
- Phaser
- Vite

## Getting started
```
npm install && npm run dev
```
